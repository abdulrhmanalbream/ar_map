## صفحة المشروع

الواجهة الجديدة تجعل `/` صفحة تعريفية عربية بهوية هداية، وشعار هداية ثون الأصلي وخط IBM Plex Sans Arabic المحلي. فيها شرح الاستخدام خطوة بخطوة، مراجع المعالم، اللغات، الساعة والمجموعة، وأسئلة عن التشغيل والخصوصية. أصبحت لوحة المشرف في `/dashboard`، مع زر للعودة إلى صفحة المشروع.

التجربة التفاعلية مرسومة ومعلّمة بوضوح «عرض توضيحي · بيانات تجريبية»: انظر، تعرّف، اسأل بلغتك، واحسب أشواطك. يتوفر تشغيل متتابع باختيار الزائر، وإيقاف وإعادة العرض، وخمس لغات، وسؤال بإجابة توضيحية، وعدّادان مستقلان من صفر إلى سبعة. تقل الحركة عند تفعيل إعداد النظام. الصفحة لا تفتح الكاميرا أو الميكروفون أو الموقع، ولا تتصل بـGemini أو API ولا تعرض بيانات الأعضاء، حتى مع وجود جلسة مشرف محفوظة.

## مجموعة للجميع

في تطبيق الجوال الجديد: افتح **المساعد والمجموعة والساعة** أو **ربط المساعد**، أدخل اسمك واختر لغتك، ثم اضغط **الانضمام للمجموعة العامة**. لا تحتاج رمز دعوة. إذا كانت لديك مجموعة خاصة فاختر **لدي رمز مجموعة خاصة**. الأعضاء المرتبطون سابقاً يبقون في مجموعاتهم.

الخادم ينشئ «مجموعة المطوف الذكي» مرة واحدة للمدير المحدد، بمعرف ثابت `smart-mutawwif-public`. إذا كان الاسم مستخدماً لمجموعة خاصة يحتفظ بها ويضيف لاحقة لاسم المجموعة العامة. الانضمام يصدر رمز جهاز مستقلاً؛ لا يفتح قوائم الأعضاء أو المواقع للزائر. الموقع والصور لهما موافقات منفصلة، والمزامنة تبدأ باختيار المستخدم. تنبيهات المساعدة والتجمع في المجموعة العامة تصل إلى أعضائها ومشرفها، كما توضّح شاشة الانضمام.

المسار الجديد هو `POST /api/v1/devices/enroll-default` بمدخلَي `name` و`language` فقط. مسار الدعوات القديم باقٍ. كلاهما يخضع لحد الطلبات والسعة السابقين. تعذّر تحديد مالك واضح يمنع الانضمام العام برسالة503، ولا يغيّر ملكية مجموعة قائمة.

## النشر المعزول

`platform/deploy/update-web.sh` ينسخ الملفات الثابتة إلى `/opt/sarab-platform/web/dist`، مع نسخة احتياطية ونشر `index.html` أخيراً، ودون إعادة تشغيل حاويات.

`platform/deploy/update-community.sh` يحدّث ملفي API الخاصين بالمجموعة فقط. يحفظ نسخة متسقة من SQLite ونسخة المصدر ورقم الصورة السابقين؛ يعيد إنشاء حاوية `sarab-platform-api-1` وحدها، ويحدّث عنوانها في Nginx الخاص بالمشروع. يقارن معرفات الحاويات الأخرى وبصمات جميع إعدادات Nginx وملفات تشغيل المشروع قبل وبعد. لا يغيّر `.env` أو TLS أو خدمات المشاريع الأخرى، ولا يعيد تحميل Nginx المضيف.

بعد النشر بقيت **15حاوية أخرى و18ملف Nginx** دون تغيير، وبصمات ملف البيئة وCompose وإعداد Nginx الخاص بالمشروع مطابقة. النسخة الاحتياطية للخادم: `/opt/sarab-platform/backups/community-20260908T133920Z`، وللواجهة: `/opt/sarab-platform/backups/web-hedaya-20260908T133938Z`. تطابق ملفا الخادم وHTML المنشور مع النسخة المحلية المختبرة.

# الداشبورد بدون تسجيل دخول

نُشر في 8 سبتمبر 2026 بعد تحديث3.1.1، دون تغيير APK الجوال أو الساعة.

- [صفحة المشروع](https://sm.hsaie.com/): شرح وتجربة توضيحية محلية.
- [الداشبورد العام](https://sm.hsaie.com/dashboard): يفتح مباشرة دون حساب، ويعرض أعداد أعضاء «مجموعة المطوف الذكي» وحالات الاتصال وطلب المساعدة والإيقاف ومشاركة الموقع واتصال Eye والساعة، وحالة خدمة المساعد. يتحدث كل خمس ثوانٍ مع زر تحديث وحالات واضحة للتحميل والانقطاع والفراغ.
- [إدارة المنصة](https://sm.hsaie.com/dashboard/admin): تسجيل دخول المشرف لعرض أسماء الأعضاء ومواقعهم المصرح بمشاركتها والمجموعات الخاصة وتفاصيل التنبيهات وإدارة المنصة.

العرض العام للقراءة فقط؛ لا يعرض أسماء أو معرفات أو إحداثيات أو رسائل أو رموز ربط. لا يقرأ جلسة المشرف المحفوظة ولا يرسلها، ولا يطلب أذونات الكاميرا أو الموقع. لا يضيف أعضاء تجريبيين. عند نشر التحديث كانت المجموعة العامة فارغة، ولذلك ظهرت الأعداد صفر بعد استجابة الخادم الفعلية.

المسار `GET /api/v1/public/dashboard` يعيد إحصاءات المجموعة العامة المحددة فقط، ويستثني الأجهزة الملغاة وكل المجموعات الخاصة. يعتبر الجهاز متصلاً إذا ورد تحديثه خلال90ثانية. أعداد اتصال النظارة والساعة للأجهزة المتصلة حالياً، بينما عدد مشاركة الموقع يعكس تفعيل الخيار حتى لو كان الجهاز غير متصل. لا يفتح أي مسار إداري أو عملية تعديل. تفاصيل الاستجابة في `platform/docs/CONTRACT.md`.

## التحقق

- الخادم:41 اختبار تكامل ووحدة ناجحاً، تشمل حدود الاستجابة المجهولة وعدم تسريب البيانات، صلاحيات المسارات، العضوية والحداثة وحد الطلبات.
- الويب: بناء TypeScript/Vite و16 اختبار وحدة ناجحاً.
- الداشبورد المنشور:14 فحص متصفح ناجحاً على360 و390 و1440بكسل، مع التحديث والتعافي من الخطأ وعزل الجلسة وحماية الإدارة. لا أخطاء صفحات أو موارد أو CSP أو طلبات API خاصة. اختبار اختلاف قيم العدادات استخدم استجابة داخل المتصفح فقط ولم ينشئ بيانات على السيرفر.
- الصفحة الرئيسية المبنية محلياً:40 فحصاً ناجحاً بعد تعديل الروابط، دون طلبات API أو أذونات أجهزة. راجعت صور الجوال والكمبيوتر.
- مساحة المشرف المنشورة: تسجيل الدخول والخريطة والمجموعات وحالة Gemini والخروج نجحت عبر TLS موثوق، ودون تجاوز عرض على الجوال أو أخطاء CSP.

تقرير الزائر: `platform/web/playwright-results/guest-dashboard/production/fieldnotes.json`؛ تقرير الرئيسية: `platform/web/playwright-results/landing/guest-regression/fieldnotes.json`؛ فحص المشرف: `platform/web/scripts/production-check.mjs`.

## النشر

حدّث `platform/deploy/update-dashboard.sh` ملفَي API المطلوبين فقط، مع نسخة متسقة من قاعدة البيانات ونسخة المصدر والصورة السابقة وإرجاع تلقائي عند فشل فحص النشر. أعيد إنشاء حاوية API الخاصة بالمشروع وحدها وتحديث Nginx الخاص بها. نُشرت الواجهة بواسطة `update-web.sh` دون إعادة تشغيل خدمات.

تأكدت مقارنة ما قبل النشر وبعده من بقاء15حاوية أخرى و18ملف Nginx دون تغيير. بقيت ملفات البيئة وCompose وTLS كما هي.

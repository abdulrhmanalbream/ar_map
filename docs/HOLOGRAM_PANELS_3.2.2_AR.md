## التغيير المطلوب

وضح المستخدم أنه يريد رؤية الكاميرا **من خلال اللوحة نفسها**. يغيّر3.2.2 مظهر اللوحات إلى صبغة خضراء خفيفة شبه شفافة، مع نص عاجي/نعناعي فاتح وظل داكن للحروف، وإطار نعناعي رفيع مضيء وزوايا محددة. لا توجد طبقة تمويه للفيديو أو حركة زخرفية مستمرة. «هولوغرام» هنا اسم للمظهر البصري فوق الكاميرا؛ ليس إسقاطاً مجسماً أو تموضعاً مكانياً جديداً.

التطبيق يستخدم طبقة واحدة بتدرج أخضر `#102C25`، بعتامة34%أعلى اللوحة و18%وسطها و26%أسفلها. النص الرئيسي `#F3FFF9`، والثانوي `#D8F4E5`، والنعناعي `#B7FFE0` مع ظل داكن؛ تعبئة زر الميكروفون الصغير50%. هذه قيم رسم داخل التطبيق، وليست قياس نفاذية للعدسات أو نسبة تباين ثابتة مع الفيديو.

يظل التخطيط والتفاعل كما في3.2.1: تفاصيل العنصر داخل واجهة الكاميرا، تعليق واضح بأن المعلومات من اللقطة المختارة، ميكروفون وإغلاق ثابتان، ونص طويل قابل للتمرير. تبدأ المحادثة بأحدث جواب، وسجلها قابل للفتح، ويظهر حقل الكتابة في بداية المحتوى عند اختيار **اكتب**.

العرضان **قراءة** و**مختصر** يختارهما المستخدم. المختصر يعرض تفاصيل أقل؛ قد يحتفظ بارتفاع القراءة نفسه في العرض الأفقي الضيق أو مع تكبير الخط. التطبيق لا يكتشف المشي أو التوقف أو العوائق، ولا يقرر أن المكان مناسب للقراءة.

دليل [لوحات3.2.1 المعتمة](AR_PANELS_3.2.1_AR.md) محفوظ كتاريخ لذلك الإصدار. العتامة ونسب التباين المقيسة فيه تخص ألوانه السابقة، ولا تصف اللوحات الشفافة الحالية.

## الاستخدام بعد التسليم

1. ثبّت APK3.2.2 كتحديث دون حذف التطبيق. Eye هي المصدر الافتراضي، وكاميرا الجوال خيار محفوظ يمكن تغييره من الإعدادات.
2. فعّل إرسال اللقطات بموافقة صريحة إذا أردت استخدام Gemini؛ اختيار المجموعة أو تغيير مظهر اللوحات لا يمنح هذه الموافقة.
3. اضغط إطار العنصر أو تسميته لفتح لوحة معلوماته. تظهر الكاميرا خلف الصبغة الشفافة، بينما تخص المعلومات والأسئلة الصورة المختارة الموضحة في التعليق.
4. اختر **مختصر** لتقليل التفاصيل أو **قراءة** للتفاصيل والمصادر. للقراءة المطولة توقف في مكان مناسب بعيداً عن مسار الحركة؛ هذا تذكير للمستخدم، لا قرار صادر من حساسات التطبيق.
5. استخدم الميكروفون أو **اكتب** للسؤال. تظل قراءة الجواب آلياً مرتبطة بتوفر خدمة النطق. أغلق اللوحة للعودة إلى البث وحالة الإيقاف المؤقت السابقة.

الفهرس الديني ومصادره والعدّاد اليدوي0–7 وسلوك حفظ صورة السؤال والتتبع المحلي2D لم تتغير. هذا تعديل واجهة، دون تغيير API أو الموقع أو الأذونات أو موافقات الصور، ودون طلب نشر جديد للخادم.

لم تُختبر هذه النسخة بعد على Fold7 وXREAL One Pro وEye. رؤية النص عبر العدسة في الشمس أو أمام أسطح ساطعة أو مزدحمة تحتاج تجربة فعلية؛ الشفافية الرقمية لا تضمن الوضوح البصري أو حجب الضوء الحقيقي. لا تثبت صور المحاكي وضوح النظارة أو دقة التعرف على المعالم ميدانياً.

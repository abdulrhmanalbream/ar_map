# المطوف الذكي 3.0.2 — هوية هداية ثون

تاريخ التسليم: 8 سبتمبر 2026. تحديث واجهات الجوال والساعة ولوحة المشرف بطلب المستخدم؛ الاسم يبقى **المطوف الذكي**.

## ما تغيّر

- هوية موحدة بالأخضر الداكن والعاجي والذهبي، وشعار هداية ثون الأصلي دون تعديل أو إعادة رسم، وخط IBM Plex Sans Arabic مضمّن مع رخصة OFL.
- الداشبورد: الدخول، المتابعة والخريطة، الأعضاء، المجموعات ورموز الربط، التنبيهات وتأكيداتها، وحالة الخدمات. نُشر على **https://sm.hsaie.com**.
- الجوال: البداية والأذونات، المساعد والمجموعة والساعة، الوجهات والخرائط والمسح ورسم الطرق، قوائم الكاميرا وإعدادات Eye. الأسهم ذهبية مع الإبقاء على حسابات الإسقاط ومسارات الحركة وحدّها الداكن.
- الساعة: ترويسة بالشعار، اختيار واضح للطواف والسعي، عرض «٠ من ٧»، إجراء تسجيل الشوط، التراجع والمساعدة وحالة الربط؛ مع حماية من أشرطة النظام وحواف الشاشة.
- إصلاح ما كشفه العرض على المقاسات الصغيرة: مساحة انتظار Eye بين أدوات التحكم في الوضع الأفقي، تكيف المساعد مع لوحة المفاتيح وتكبير الخط، تمرير قائمة الأماكن وأدواتها كاملة، والتفاف حالة الخدمات في الداشبورد عند عرض 320px.

## التحقق

- `build.ps1 -Test` نجح بعد إصلاحات العرض: 342 اختبار JVM للجوال و15 للساعة، صفر فشل أو أخطاء أو تخطٍ. Lint صفر أخطاء؛ بقيت تحذيرات غير مانعة (144 للجوال، 3 للساعة).
- توقيع الملفين تحقق بـ`apksigner`، والشهادة متطابقة. الحد الأدنى Android API24 للجوال وAPI30 للساعة، والمستهدف API35.
- 10 اختبارات ويب وبناء الإنتاج ناجحة. 39 فحص شاشة/مقاس محلي تغطي الدخول والمتابعة والتفاصيل والربط والتنبيهات والأخطاء، دون تجاوز أفقي أو أخطاء JavaScript. فحص التصميم الآلي مرة واحدة لم يسجل ملاحظات؛ مراجعة مستقلة أكدت الإصلاح عند عرض 320px.
- فحص Chrome على الدومين الفعلي نجح للدخول والخروج والمتابعة والمجموعات والخدمات وعرض الجوال؛ شهادة موثوقة، صفر أخطاء CSP أو JavaScript أو استجابات موارد محلية فاشلة.
- فحص المحاكي شمل انتظار Eye الأفقي، الوجهات، نموذج الربط، المساعد والمجموعة، والمساعد/الربط مع لوحة المفاتيح عند 320×640dp وخط 130%. شاشة الساعة فُحصت على محاكي نظام هاتف بمقاس 450×450px، مع التسجيل والتراجع والتبديل بين العدّادين. هذه ليست تجربة على ساعة فعلية أو اختباراً جديداً لاقتران Bluetooth أو الاهتزاز.
- شاشتا المساعد والمجموعة استُعرضتا ببيانات اختبار محلية معنونة «معاينة محلية للواجهة» وعنوان loopback غير متصل، دون جلسة أو إرسال بيانات إلى الإنتاج. لم تُنشأ مجموعات أو تنبيهات إنتاجية في هذا التحديث.

## النشر وحفظ الخدمات

نُشرت ملفات الويب فقط داخل `/opt/sarab-platform/web/dist` بواسطة `platform/deploy/update-web.sh`. حُفظ مجلد الربط نفسه، ونُسخت الموارد قبل تبديل `index.html`، وبقيت الموارد القديمة متاحة. لا إعادة تشغيل أو إعادة إنشاء لحاويات أو Nginx، ولا تغيير لقاعدة البيانات أو ملفات البيئة أو الشهادات.

التحقق قبل/بعد أثبت بقاء معرّفات الحاويات الـ16، و18 بصمة إعداد Nginx، وPID ووقت تشغيل Nginx كما هي. مؤقت TLS ظل فعالاً. نسخة الرجوع محفوظة على الخادم في `/opt/sarab-platform/backups/web-hedaya-20260908T113625Z`.

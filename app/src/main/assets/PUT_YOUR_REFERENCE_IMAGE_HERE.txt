PUT YOUR REFERENCE IMAGE IN THIS FOLDER
=======================================

This folder is:
    app/src/main/assets/

Save your printed map-board photo here with EXACTLY one of these names:

    origin_marker.jpg     <-- preferred
    origin_marker.png
    map_board.jpg
    map_board.png
    qr_code.jpg
    qr_code.png

The app checks those names in that order and uses the first one it finds.

Then rebuild:
    .\build.ps1 -Install

WITHOUT an image here the app still works: it falls back to placing the route
on the floor in front of you. The image only makes the origin fixed and
repeatable, which is what makes a real campus route line up correctly.

IMPORTANT: the physical printed width must match the value in
app/src/main/java/com/sarab/vision/ar/AugmentedImageSupport.kt

    const val ORIGIN_IMAGE_WIDTH_METERS = 0.30f   // 30 cm wide

If you print at a different size, change that number to match, or the route
will be scaled wrong.

Full instructions, including what makes a GOOD reference image, are in
V2_SETUP.md in the project root.

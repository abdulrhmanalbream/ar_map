# المطوف الذكي operational dashboard

Mode: Operate. The explicit brief pins a light ivory and teal workspace. Under bright office/daylight conditions, dark text and pale surfaces keep member details readable.

Display name: **المطوف الذكي**. English wordmark: **Smart Mutawwif**. The Arabic name remains a single readable line, with a smaller size in the sidebar/mobile header so its longer wording does not compete with navigation. The existing geometric symbol is retained.

Use one locally bundled Noto Sans Arabic family (400, 500, 600, 700), fixed rem type, 16px base. Main ink #193c39, muted #65726c, canvas #f5f5ef, surface #ffffff, primary #18675a, sidebar #153f3b. Teal is used for primary actions, active navigation and active status. Amber and red convey stale data and help. Text labels always accompany status colors.

Desktop: right navigation rail, content header, a single horizontal status strip, then map plus the member roster. The map is the dominant work surface; no decorative scene, fake statistics or decorative mini charts. Mobile navigation becomes a compact top row, the map and list stack, and every control remains reachable.

Buttons and form controls use consistent 10px corners, visible 2px focus outlines, 44px touch targets. Panels use a single subtle border with 14px corners. No decorative shadows or gradients. Motion is limited to 160ms state transitions and respects reduced motion.

Help, offline, stale location, absent consent, empty, loading, errors and pending mutations all have explicit text. Enrollment codes are selectable, time-limited and hidden until explicitly generated. Alert delivery and acknowledgement remain distinct.
